Analog design

Low-Dropout Regulator — Analog Design & Layout

1.8 V to 1.2 V CMOS LDO with PMOS pass device, closed-loop feedback, and verified loop stability

Cadence Virtuoso · Spectre · GPDK45

Role in the project

Sole author: architecture selection, transistor-level design, device sizing and biasing, DC / transient / PSRR / loop-stability simulation, full-custom layout, and physical verification.

Load current approximately 1 mA. These are the verified simulation results; line regulation, load regulation, output noise, and load-step transient response are not claimed here because they are not part of the documented result set.

Analog design focus

  • Regulator architecture — error amplifier driving a PMOS pass device inside a resistive feedback loop, chosen for low dropout at the target headroom.
  • Pass-device behaviour — the PMOS is sized for the dropout target at the intended load current; its size also sets the dominant pole location at the output, which is why sizing and stability are the same decision.
  • Error amplifier — sets loop gain and therefore regulation accuracy, while its output impedance interacts with the pass-device gate capacitance.
  • Feedback network — the resistive divider fixes the output voltage against the reference and contributes to loop dynamics.
  • Biasing — bias current sets amplifier transconductance and therefore both loop gain and quiescent current.
  • Dropout behaviour — how far the input can fall before the pass device leaves its regulating region.
  • Loop stability and compensation — the 90.46° phase margin reflects a deliberately conservative, well-damped loop.
  • PSRR — supply-ripple rejection across frequency, and how it degrades as loop gain rolls off.
  • Layout parasitics — resistance in the pass-device and output routing appears directly as regulation error, so those paths were widened.

Design flow

Specification→Architecture→Schematic→Sizing & biasing→Pre-layout sim→Layout→DRC / LVS / ERC→PEX→Post-layout

Layout and verification

  • Wide, low-resistance routing on the pass-device and output nets.
  • Matched, symmetric placement for the error-amplifier input pair.
  • Guard rings around sensitive analog devices.
  • DRC, LVS, and ERC clean; PEX and pre-/post-layout comparison run where extraction was available.

Key learnings

  • Pass-device sizing is a stability decision as much as a dropout decision.
  • A very high phase margin buys robustness but costs loop bandwidth and transient recovery speed.
  • Output-path routing resistance shows up as regulation error that no amount of loop gain hides.
