Analog layout

Bandgap Reference — Analog Design & Full-Custom Layout

PTAT and CTAT compensated voltage reference with a 5 × 5 common-centroid BJT array

Cadence Virtuoso · GPDK45

Role in the project

Sole author: reference architecture, transistor and device-level schematic design, pre-layout simulation, full-custom matching-driven layout, and DRC/LVS/ERC verification.

Temperature-coefficient and absolute output-voltage figures are not claimed on this page — those results are not part of the documented result set for this block.

Circuit design

  • Reference generation concept — a PTAT term derived from the difference in base-emitter voltage between unequally sized BJT branches is summed with the CTAT base-emitter voltage itself, so the two opposing temperature slopes partially cancel.
  • Biasing — branch currents are set so that both BJT branches operate at the intended current-density ratio, since that ratio is what produces the PTAT term.
  • Device matching — the reference's accuracy is bounded by how well the BJT array and the resistors match, not by the amplifier.
  • Temperature compensation — the weighting between PTAT and CTAT contributions determines where the curvature minimum sits.
  • Simulation — DC operating-point and temperature-sweep analysis to confirm the compensation behaves as intended.

Layout design

  • 5 × 5 common-centroid BJT array — the unequal-area devices are distributed symmetrically about a shared centroid so linear process and thermal gradients cancel to first order.
  • Resistor matching — identical unit resistors in the same orientation, since the reference depends on a resistor ratio rather than an absolute value.
  • Symmetry — both branches routed identically so interconnect parasitics match.
  • Dummy devices at array edges to equalise the local etch and stress environment.
  • Guard rings around the array for substrate-noise isolation and latch-up prevention.
  • Parasitic-aware routing on the high-impedance summing nodes.

Verification

DRC, LVS, and ERC clean in Cadence PVS, with iterative debug of spacing, enclosure, and connectivity violations introduced by the dense array routing.

Key learnings

  • In a bandgap the layout is the design; a schematically perfect reference matches only as well as its array does.
  • Common-centroid arrangement only cancels gradients if the routing is symmetric too.
  • Ratio-based design is far more robust than absolute-value design in a CMOS process.
